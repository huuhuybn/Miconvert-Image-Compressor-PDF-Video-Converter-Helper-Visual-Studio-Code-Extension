# Changelog

All notable changes to the "Miconvert: Image Compressor, PDF & Video Converter Helper" extension will be documented in this file.

## [0.0.2] - 2026-02-14

### Changed
- SEO-optimized display name and description for better Marketplace discoverability
- Expanded keywords to include PDF, video, converter, compressor
- Full README rewrite with keyword-rich content, backlinks, FAQ, and online tools table

### Added
- "Rate us ⭐" review prompt — appears randomly after 5+ successful compressions
- "Don't ask again" option to permanently dismiss rating prompt
- Translated rating strings for all 10 supported languages

## [0.0.1] - 2026-02-14

### Added
- Right-click context menu to compress individual images (PNG, JPG, WebP)
- Bulk folder compression with recursive scanning and progress bar
- Smart status bar showing image file size with warning for large files (>500KB)
- Configurable compression quality (1-100)
- Overwrite or create `_min` suffix options
- Format conversion to WebP or JPEG
- File size threshold to skip small files
- Welcome message on first install
- Video file upsell → miconvert.com
- Unsupported format redirect to miconvert.com
